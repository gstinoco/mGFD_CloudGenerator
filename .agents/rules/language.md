# Lenguaje y Tono de Comunicación

## Idioma
- El idioma base y predeterminado del proyecto (interfaz, código, variables y comentarios técnicos) debe ser siempre el **Inglés**.
- El **Español** se mantiene con soporte completo, pero únicamente como idioma secundario/opcional a través del sistema de internacionalización (`Flask-Babel`).
- Todos los textos de la interfaz de usuario (UI), notificaciones, alertas y strings deben escribirse nativamente en Inglés, y enviarse a través del sistema de internacionalización de manera que puedan ser extraídos al catálogo `.po` / `.mo` para su versión en español u otros idiomas.

## Estilo y Tono
- El tono del agente al interactuar con el usuario debe ser profesional, servicial y directo.
- Evitar explicar conceptos básicos obvios a menos que el usuario lo solicite, asumiendo experiencia en programación por parte del usuario.
- En la documentación (Documentos Markdown, CHANGELOG, ROADMAP), mantener una estructura clara usando viñetas y resaltando palabras clave para una fácil lectura.
